Senior Data Engineer / BI Developer – Microsoft Data Platform
Eurolife FFH · Central Athens, Attiki, Greece

About The Role

At Eurolife FFH, we are constantly looking for smarter ways to use data to strengthen decision-making, improve our operations and deliver better outcomes for our customers and people.

As a Senior Data Engineer / BI Developer, you will play a key role in designing, developing and optimising enterprise Data Warehousing, Data Integration and Business Intelligence solutions.

This is a hands-on technical position, focused on designing, building, implementing, and optimizing data solutions. We are looking for someone who enjoys solving complex technical challenges and delivering solutions directly, rather than managing teams.

What You Will Do
- Design, develop, and maintain enterprise Data Warehouses, Data Marts, and analytical data models.
- Develop, maintain, and optimize ETL/ELT processes and data integration pipelines using SQL Server Integration Services (SSIS), Azure Synapse Pipelines, and Microsoft Fabric.
- Design and implement data transformation and integration solutions across multiple data sources and systems.
- Build and optimize advanced SQL queries, stored procedures, functions, and database objects using T-SQL.
- Develop and maintain Power BI semantic models, dashboards, and reports, including advanced DAX calculations.
- Work with SQL Server Analysis Services (SSAS), including tabular and multidimensional models where applicable.
- Implement and maintain CI/CD processes, version control, and automated deployments using Azure DevOps.
- Optimize data processing, query performance, reporting efficiency, and overall solution scalability.
- Support data quality, consistency, governance, and reliability across data platforms.
- Collaborate directly with business stakeholders, analysts, and technical teams to translate requirements into working technical solutions.
- Troubleshoot complex data integration, performance, and reporting issues.

What We Are Looking For
- 5+ years of hands-on experience in Data Engineering, Data Warehousing, Business Intelligence, or related areas.
- Strong expertise in Microsoft SQL Server and advanced T-SQL development.
- Experience in designing and implementing Data Warehouses, Data Marts, and dimensional data models.
- Experience with ETL/ELT development, particularly SSIS and/or Azure Synapse Pipelines.
- Practical experience with Azure Synapse Analytics, including pipeline orchestration, data transformation, and integration.
- Hands-on experience with Microsoft Fabric and its data engineering and analytics capabilities.
- Strong Power BI development skills, including semantic modeling, DAX, Power Query, and report optimization.
- Experience with Azure DevOps, Git, CI/CD pipelines, and deployment processes.
- Solid understanding of data modeling concepts, including star schemas, fact and dimension tables, and data warehouse architecture.
- Strong analytical, troubleshooting, and performance-tuning skills.
- Ability to independently develop and deliver production-ready technical solutions.

Additional Experience We Value
- Experience with Microsoft Fabric Lakehouse, Warehouse, Data Factory, and OneLake.
- Practical experience with AI technologies, including Generative AI, Large Language Models (LLMs), and AI-assisted development tools such as GitHub Copilot.
- Experience using Visual Studio Code (VS Code) for development, debugging, and integration with Git and Azure DevOps.
- Experience with Azure Data Lake Storage Gen2.
- Understanding of data governance, security, and access management.
- Experience with financial, insurance, or other data-intensive enterprise environments.
- Relevant Microsoft certifications in Azure Data Engineering, Fabric, Power BI, or AI-related technologies.

Beyond Technical Expertise, We Are Looking For Someone Who
- Is genuinely hands-on and enjoys writing SQL, building pipelines, developing data models, and creating BI solutions.
- Takes ownership of technical deliverables from design through production.
- Can work independently while collaborating effectively with other technical and business stakeholders.
- Has a problem-solving mindset and pays attention to performance, reliability, and maintainability.
- Is comfortable working with both established Microsoft BI technologies and newer cloud-based data platforms.
- Values technical excellence and continuous learning.

- Gain exposure to modern Microsoft data technologies, including Azure Synapse, Microsoft Fabric, and Power BI.
- Take end-to-end ownership of technically challenging solutions.
- Work in a collaborative environment that values engineering expertise, continuous learning and practical problem-solving.
