Job Description

We are looking for a Power BI & Python Web Developer with experience in data visualization, web development, and API integration. The ideal candidate will combine Power BI expertise with Python development skills to build interactive dashboards, develop backend functionalities, and integrate data from different sources.
The role requires hands-on experience with Python, REST APIs, and AWS services, particularly AWS Lambda, to develop and maintain data processing solutions and support end-to-end data integration workflows.
Responsibilities

- Design, develop, and maintain interactive Power BI dashboards and reports, ensuring usability, performance, and effective data visualization.

- Connect Power BI to multiple data sources, including relational databases, REST APIs, and files.

- Develop web applications, backend services, and data processing solutions using Python.

- Design, develop, consume, and maintain REST APIs to enable communication between applications and data sources.

- Develop and maintain AWS Lambda functions for serverless processing, data transformation, and integration tasks.

- Process and transform data using Python libraries such as Pandas and NumPy before making it available for reporting and visualization.

- Collaborate with technical and business teams to understand requirements and translate them into effective technical solutions.

- Apply CI/CD practices and version control to ensure code quality, maintainability, and reliable deployments.

Qualifications

- 2–3 years of experience working with Power BI, including dashboard development, data modeling, and data visualization.

- Experience in web development using Python, including backend development and data processing.

- Experience designing, developing, and consuming REST APIs.

- Hands-on experience with AWS Lambda for developing and deploying serverless functions.

- Experience working with relational databases and SQL.

- Proficiency in Python libraries such as Pandas and NumPy for data manipulation and transformation.

- Experience with CI/CD practices and software development workflows.

- Advanced knowledge of Git and version control.

- Understanding of software development best practices, code quality, and application integration.

Nice to Have

- Hands-on experience with FastAPI or other Python web frameworks.

- Experience with AWS services beyond Lambda, particularly those used for data integration and processing.

- Familiarity with DevOps tools and practices, including Docker and Kubernetes.

- Experience with automated testing and deployment pipelines.

- Knowledge of cloud-based architectures and serverless application development.
