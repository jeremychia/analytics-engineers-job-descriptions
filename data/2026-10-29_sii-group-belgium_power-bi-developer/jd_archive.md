Power BI Developer

- Strong SQL skills for database design (SQL Server, Oracle, PostgreSQL), and manipulation and optimization of complex queries.

- Proficiency in one or more programming or scripting languages for ETL and interface development (Python, C#, SQL Server Integration Services (SSIS), or other ETL tools).

- Knowledge of APIs to integrate and drive system-to-system exchanges.

- Attention to code robustness, security, and maintainability.

- In-depth knowledge of Data Warehouse concepts and best practices (modeling, normalization, historization management).
