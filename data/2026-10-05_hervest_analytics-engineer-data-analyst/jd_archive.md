- Own the BI Layer: Serve as the primary administrator for our Metabase instance. You will build comprehensive dashboards, configure native SQL queries into reusable Metabase Models, and set up field filters for non-technical users.
- Advanced Data Modeling: Write complex, performant SQL (CTEs, Window Functions, JSONB extraction) in PostgreSQL and MySQL to transform raw application data into clean reporting tables.

Requirements

- SQL Mastery: 3+ years of experience writing advanced, production-grade SQL. You must be highly proficient in both PostgreSQL and MySQL dialects.
- Metabase Expertise: Deep experience building dashboards, writing native SQL within Metabase, configuring variables, and managing Metabase environments.
- Database Fundamentals: A strong understanding of relational database architecture, foreign keys, normalization, and the performance implications of querying live replicas.
- Analytical Mindset: The ability to take a vague business question (e.g., "What is our month-over-month active user retention?"), find the right tables, and visualize the answer accurately.
