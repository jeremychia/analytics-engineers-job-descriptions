We run a creator platform, we are based in Rotterdam. The product is new, the data foundation is in place, and we are taking it further now.

The role
The data warehouse already exists: BigQuery with dbt transformations, Looker on top. What we need now is someone to own the layer between raw data and the business: finished mart models, metric definitions people can trust, and a Looker project that stays maintainable as the transformations underneath it keep moving.
The ideal candidate is as interested in the definitions as in the code: curious about how the business actually works, comfortable sitting with finance, marketing or product to get to the real rule behind a question, and committed to writing it down so the answer holds up the next time it comes up.

What you will do
- Own the LookML project end to end: models, views, explores, derived tables, persistence
- Build and maintain the dbt mart layer underneath it
- Define metrics together with finance, marketing and product, then document and materialise them
- Build data models that other systems consume, not only dashboards
- Keep query cost and performance under control as usage grows

What we're looking for
- Hands-on Looker experience (LookML, not Looker Studio). You have worked inside a LookML project, not only viewed dashboards. We care more about what you have built than how long it took
- dbt in production: layered architecture, incremental models, testing, documentation, and the discipline to keep a project maintainable as it grows
- Advanced SQL on a cloud data warehouse, with real awareness of cost and performance
- An eye for what makes a dashboard good. Not a wall of charts, but a clear answer to a question, laid out so a non-technical colleague understands it without a walkthrough and keeps using it daily
- Experience building data models other systems depend on
- Working knowledge of Python for automation and pipeline work
- Proactive and structured. In an early setup, nobody hands you a backlog
- Fluent English
- The right to work in the Netherlands. We are not able to sponsor work visas or relocation for this role

Nice to have
- Data quality and observability: testing at scale, freshness and anomaly monitoring, alerting
- Handling data arriving via Pub/Sub
- Looker API or SDK, Looker Actions, scheduled delivery automation
- GDPR and PII handling in a warehouse context
- Machine learning experience

Tech stack
- Google Cloud Platform
- Google BigQuery
- Looker / LookML
- dbt & SQL
- Python
- Git

Practical

- On-site in Rotterdam. We work from the office most of the week, so we are looking for people in or around the region
