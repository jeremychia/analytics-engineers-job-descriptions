about the company
Randstad has recently partnered with an MNC organisation with a global presence, focusing on solutions targeting the real estate and engineering industry. Your future employers builds long-term partnerships with their clientele, offering timely and reliable solutions to their business needs.

key responsibilities:
- End-to-End BI Development: Manage the complete BI lifecycle, including requirements gathering, data modeling, ETL design, semantic layer creation, and final visualization.
- Data Visualization: Design, develop, and maintain high-performance, interactive dashboards and reports using Power BI (including DAX and Power Query).
- Legacy & Modern Reporting: Build and manage automated, paginated enterprise reports using SSRS (SQL Server Reporting Services).
- Data Integration (ETL): Design and maintain robust data integration workflows using SSIS (SQL Server Integration Services) to extract, transform, and load data from various sources into our data warehouse.
- Cloud Architecture: Leverage Microsoft Azure cloud services (such as Azure SQL, Azure Data Factory, or Azure Synapse) to modernize and scale our BI infrastructure.
- SQL Query Optimization: Write, troubleshoot, and optimize complex SQL queries, stored procedures, and views. Proactively identify and resolve performance bottlenecks in slow-running queries.
- Business Analytics: Act as a data partner to the business. Answer ad-hoc analytical questions, identify data trends, and help stakeholders understand the "why" behind the metrics.

requirements:
- Experience: Proven track record in an end-to-end BI Developer or similar role, successfully delivering data projects from source systems to end-user dashboards.
- Core BI Tools: Expert-level proficiency in Power BI, with strong skills in data modeling and DAX calculations.
- Microsoft Stack: Deep, hands-on experience with the traditional SQL Server BI stack, specifically SSIS and SSRS.
- Database Mastery: Advanced SQL skills with a strong emphasis on query tuning, indexing, and database performance optimization.
- Cloud Exposure: Practical experience deploying or managing data solutions within the Microsoft Azure cloud ecosystem.
- Analytical Skills: Strong problem-solving abilities with a knack for analyzing data sets to extract business insights, not just fulfilling reporting requests.

nice to have:
- Experience migrating legacy on-premise SSIS/SSRS workloads into Azure native services (like Azure Data Factory and Power BI Paginated Reports).
- Knowledge of Python or R for statistical analysis and advanced data manipulation.
